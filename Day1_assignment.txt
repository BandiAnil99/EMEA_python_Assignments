1. Supermarket Discount


User Story:

A supermarket wants to automatically calculate discounts for customers.

If the customer's bill is ₹1,000 or more, they should receive a 20% discount.

If the bill is ₹500 or more, they receive a 10% discount.

Otherwise, there is no discount.


Task:

Write a Python program that takes the bill amount from the user and calculates the discount.


Answer:


bill = int(input("Enter your bill:"))


if bill >= 1000:

    discount = bill * 0.2

elif bill >= 500:

    discount = bill * 0.1

else:

    discount = 0


print(discount)

2. Bank Withdrawal


User Story:

A bank customer wants to withdraw money from their account.

The bank should allow the withdrawal only if the requested amount is less than or equal to the available balance.


Task:

Write a program that asks for the balance and withdrawal amount and displays either

"Withdrawal successful" or "Insufficient balance".


Answer:


balance = float(input("Enter your balance:"))

amount = float(input("Enter amount you want to withdraw:"))


if amount <= balance:

    balance -= amount

    print("Withdrawal successful")

else:

    print("Insufficient balance")

3. ATM PIN


User Story:

An ATM gives a customer a maximum of 3 attempts to enter the correct PIN.

If the PIN is correct, access should be granted immediately.

If all 3 attempts fail, the card should be blocked.


Task:

Write this using a while loop.


Answer:


pin1 = int(input("Actual pin:"))


x = 3


while x:

    pin2 = int(input("Enter pin:"))


    if pin1 == pin2:

        break

    else:

        x -= 1

else:

    print("Card got blocked")

5. Shopping Cart


User Story:

A customer has five products in their shopping cart.

Products costing less than ₹100 are promotional items and should not be included in the calculation.


Task:

Use a for loop and continue to calculate the total.


Answer:


size = 5

prod = [0] * size


price = 0


for i in range(5):

    prod[i] = float(input(f"Enter item price of {i}:"))


    if prod[i] >= 100:

        price = price + prod[i]

    else:

        continue


print(price)

6. Bank Minimum Balance


User Story:

A bank requires customers to maintain a minimum balance of ₹2,000.

After a withdrawal, if the balance falls below ₹2,000, the customer receives a warning.

    balance = balance - wdraw_amount

    print(balance)


    if balance < 2000:

        print("Alert ! Please maintain minimum balance of 2000")

else:

    print("Insufficient balance")

8. ATM Cash Dispensing


User Story:

An ATM dispenses ₹500 notes.


Answer:


amount = int(input("Enter amount:"))


cnt = 0


if amount % 500 == 0:


    while amount:

        amount -= 500

        cnt += 1


else:

    print("Cancel it and Please enter amount again in multiples of 500")


if cnt:

    print("Total number of notes:", cnt)

User Story:

Reduce the available credit limit after every purchase.

    prod_price = int(input("Enter price of prod:"))

        credit_limit = credit_limit - prod_price

    else:

        break

20. Bank Transaction Analyzer


User Story:

transactions = [500, -200, -1000, 300, -500, 2000]


Positive values → Deposits

Negative values → Withdrawals


Task:

1. Calculate total deposits

2. Calculate total withdrawals

3. Calculate final balance change

4. Count withdrawals


Answer:


transactions = list(map(int, input("Enter the transactions: ").split()))


dep = 0

wd = 0

final_bal = 0

cnt_w = 0


for i in transactions:


    if i >= 0:

        dep += i

    else:

        wd += abs(i)

        cnt_w += 1


    final_bal += i


print("Total deposits:", dep)

print("Total withdrawals:", wd)

print("Final balance:", final_bal)

print("Count of withdrawals:", cnt_w)
